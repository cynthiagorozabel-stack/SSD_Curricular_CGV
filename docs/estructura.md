# 2. Estructura del Proyecto

- **ssd_core/**: Lógica principal, motores de cálculo, validaciones y exportaciones.
- **export/**: Archivos de salida y resultados.
- **config/**: Archivos de configuración y datos base.
- **audit/**: Trazas de auditoría.
- **docs/**: Documentación.

Cada módulo está diseñado para máxima trazabilidad y robustez.
