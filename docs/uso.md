# 6. Uso y Ejecución

1. Activar el entorno virtual: `venv`.
2. Ejecutar el pipeline principal:
   ```
   $env:PYTHONPATH = '.'; python ssd_core/main.py --carrera_id=101
   ```
3. Los resultados se generan en la carpeta `export/`.
4. Consultar los archivos de análisis y trazabilidad para validación y auditoría.
